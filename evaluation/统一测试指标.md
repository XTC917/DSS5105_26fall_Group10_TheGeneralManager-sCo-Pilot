# 统一测试指标

按现在这一版 Co-Pilot 测。每项在 **通过 / 部分通过 / 不通过** 里勾一个。

除时间相关的测试外，请将Factory Date 设置为**4/1**.

**通过**：和通过标准一致。  
**部分通过**：测试偶发存在的问题，问题基本不影响回答或使用。  
**不通过**：测试可复现存在的问题，问题影响回答和使用。  

**部分通过/不通过的问题请在备注中提供当前的登陆账号，提问的问题和对应的问题描述。**

测完复制本文件，命名 `统一测试指标_<姓名>.md`。
**所有前端美化相关建议可以立即发送到群里，无需记录在此**
