# 人工评分 SOP

和机器的文字评分用同一套梯子。每人评自己那 22 题。工厂日固定为 **2026-04-01**。

## 每题怎么做

1. 新开一轮对话再问。
2. 等回答结束。记录问题原文和正文。
3. 如果模型跳出澄清，按照最符合标答的澄清选项来进行选择。
4. 找到 `expected_answer`根据下面的指标进行评估，定位L0-L3
5. 根据标准划分并标注对应等级
6. 每题提问两遍

## L0-L3定义

L1 — Basic Correctness：核心事实和结论正确，没有关键性错误。
L2 — Analytical Completeness：满足 L1，并提供必要的数据依据、风险解释或业务逻辑。
L3 — Decision-Ready Answer：满足 L1、L2，同时提供符合问题目的的深入判断、关联分析或可执行建议。
只有满足 L1 才能获得 L2，只有满足 L1 和 L2 才能获得 L3。如果连 L1 都未达到，则判为 L0 — Fail。

## 等级

| 等级 | 什么时候给 | 计入准确率 |
| --- | --- | --- |
| A+ | L3。事实对，而且有深入判断、关联或可执行建议 | 是 |
| A | L2。事实对，也有本题需要的数据、风险或业务逻辑，但没有 L3 那一层 | 是 |
| A- | 只有 L1。核心事实对，但没有分析 | 否 |
| B+ | L0，因为正文是空的，或是“这次没能完成回答。请再试一次。” / “I couldn't finish that answer. Please try again.” | 否 |
| C | L0，因为核心事实或结论是错的 | 否 |

准确率 = (A+ 的题数 + A 的题数) / 本组题数。A-、B+、C 都在分母里。

## 交回

每题一条：

```json
{"id": "ETS-068", "level": "L2", "grade": "A", "counted": true, "reason": "一句话"}
```

`counted` 只有 A+ 和 A 为 true。另交本组准确率，以及最满意的三题、最失望的三题，各一句原因。不够三题就写实际有的。
